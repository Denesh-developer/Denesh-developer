# Publish instructions

1. Create a **public** GitHub repository named exactly `Denesh-developer` (same as your GitHub username).
2. Upload the contents of this folder to the repository root. Keep the `assets/` and `.github/workflows/` folder structure.
3. Make sure the repository's default branch is the branch receiving these files (usually `main`).
4. Open **Actions** in the repository. If prompted, enable GitHub Actions.
5. Open **Generate contribution snake** and choose **Run workflow** once. It will also run daily.
6. The workflow publishes the generated snake SVGs to a branch named `output`.

The README and custom SVG assets are ready to publish as-is. The snake workflow is included as an optional extra; the README does not embed it yet, so no broken image appears before the first successful workflow run.
